## Classroom Manager 2.0 — Liquid Glass Edition

Полное обновление визуального стиля, удобства управления и системных иконок Windows!

### Что нового в v2.0.0
- **Новый интерфейс в стиле Apple iOS / macOS Liquid Glass (`Dark` & `Light`):**
  - Пространственный фон с мягким свечением, полупрозрачные матовые стеклянные панели с бликом граней и мгновенное переключение между тёмной и светлой темой без перезапуска.
  - Разгруженная контекстная верхняя панель: быстрые действия выбранного ПК отображаются только на вкладке экранов и не загромождают терминал PowerShell и журнал событий.
  - Мгновенный поиск по имени парты, пользователю Windows или IP-адресу.
  - Быстрые иконки прямо на карточке каждого ученика: **HD-управление** и **Блок/Разблок экрана** в 1 клик.
- **Фирменные системные иконки Windows (`.ico` `16–256px`):**
  - Кастомные мультиразмерные иконки Liquid Glass для `ClassroomTeacher.exe` и `ClassroomStudent.exe` в Проводнике Windows, папке «Загрузки», на Рабочем столе, в `Alt+Tab` и на Панели задач Windows 10/11 (`AppUserModelID` + нативный тёмный/светлый заголовок окна DWM).
- **Улучшенные диалоги и Drag & Drop раздача файлов:**
  - Перетаскивайте файлы прямо из Проводника в окно передачи файлов (с контролем `SHA-256` и автооткрытием у учеников).
  - Обновлённая плавающая HUD-панель в полноэкранном HD-управлении ПК (`1:1`, выбор монитора ученика, компактное меню питания).
  - Обновлённые защищённые настройки агента ученика с индикатором статуса и кнопками показа/скрытия паролей и ключей.

### Файлы релиза (не требуют установки Python)
- **`ClassroomTeacher.exe`** — консоль преподавателя (Liquid Glass UI)
- **`ClassroomStudent.exe`** — фоновый агент для компьютеров учеников (системный трей)
- **`setup_firewall.ps1`** — однократная настройка правил Брандмауэра Windows для LAN
