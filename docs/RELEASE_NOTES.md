## Classroom Manager v2.2.0 – Встроенный MCP для ИИ, улучшенная эргономика и иконки

### Что нового в v2.2.0
- **Встроенный MCP-сервер для подключения нейросетей к PowerShell класса:**
  - Прямо во вкладке **«Терминал PowerShell»** появилась панель **MCP-сервера** (`http://127.0.0.1:45460/mcp` с защитой Bearer-токеном и привязкой только к `localhost`).
  - Кнопка **«Копировать JSON»** копирует готовый конфиг `mcpServers` для Antigravity, Claude Desktop, Cursor, VS Code и Windsurf.
  - Нейросеть получает инструменты: `list_classrooms`, `list_students`, `get_system_info`, `run_powershell`, `run_powershell_all`, `send_message`, `set_screen_lock`, `send_file` – можно одной фразой настроить ПО или проверить окружение сразу на всех ПК учеников.
- **Исправлены отступы и композиция интерфейса:**
  - В разделе **PowerShell** добавлены чёткие отступы между блоками (библиотека команд и редактор/консоль больше не сливаются), а кнопка «Выполнить (цель)» корректно отключается при отсутствии подключённых ПК.
  - На вкладке **«Экраны класса»** убрана пустая полоса «ПК не выбран» с пустым пространством – панель действий появляется автоматически при наличии подключённых учеников и аккуратно выровнена слева (`Выбран: Парта-01` + кнопки сразу рядом).
  - Заменена иконка **Настроек** на классическую чёткую шестерёнку.
  - Приведена в порядок типографика: убраны лишние разделители-точки и длинные тире, использованы аккуратные средние тире (`–`) и естественные пробелы.

### Файлы релиза (не требуют установки Python)
- **`ClassroomTeacher.exe`** – консоль преподавателя (Liquid Glass UI + мульти-кабинеты + MCP для ИИ)
- **`ClassroomStudent.exe`** – фоновый агент для компьютеров учеников (системный трей)
- **`setup_firewall.ps1`** – однократная настройка правил Брандмауэра Windows для LAN
