## Classroom Manager v2.1.0 — Мульти-кабинеты и улучшенные состояния UI

### Что нового в v2.1.0
- **Поддержка нескольких кабинетов (Multi-Classroom):**
  - Добавляйте сколько угодно кабинетов (`Cab-101`, `Cab-204`, `Lab-IT` и др.) прямо из боковой панели кнопкой **`+`** — у каждого кабинета свой `ID` и отдельный ключ доступа `PSK`.
  - Мгновенно переключайтесь между кабинетами или выбирайте режим **«Все кабинеты»**; автопоиск `UDP Smart Discovery` и `TLS/HMAC`-аутентификация одновременно обслуживают все добавленные кабинеты.
- **Понятные состояния кнопок (активные / неактивные / некликабельные):**
  - Неактивные и недоступные кнопки теперь визуально приглушены (полупрозрачный фон, пунктирная рамка, затемнённая иконка), меняют курсор на запрещающий и показывают понятную подсказку при наведении (почему действие сейчас недоступно).
  - Умная подсветка блокировки: если выбранный ПК открыт — активна кнопка **«Блок»**, а **«Разблок»** неактивна; если ПК заблокирован — **«Блок»** отключается, а **«Разблок»** подсвечивается зелёным.
  - Точно так же автоматически обновляются массовые кнопки **«Блок всех»** / **«Разблок»**, **«Демонстрация экрана»**, **«Отправить файлы»** и **«Удалить кабинет»**.
- **Чистый экран блокировки:**
  - Убраны лишние скобки в подписи под заголовком `ЗАБАНЕН` — теперь отображается аккуратная строка `срок бана: 1000 лет`.

### Файлы релиза (не требуют установки Python)
- **`ClassroomTeacher.exe`** — консоль преподавателя (Liquid Glass UI + мульти-кабинеты)
- **`ClassroomStudent.exe`** — фоновый агент для компьютеров учеников (системный трей)
- **`setup_firewall.ps1`** — однократная настройка правил Брандмауэра Windows для LAN
