## Classroom Manager v3.0.1 — Сохранение пароля учителя и автовход

### Что нового в v3.0.1
- **Сохранение пароля учителя (автовход):**
  - В окне входа учителя добавлен чекбокс **«Сохранить пароль (входить автоматически)»** — после включения панель учителя больше не запрашивает пароль при каждом запуске.
  - Опция также доступна в мастере первичной настройки и в **Настройках класса** (можно в любой момент включить или снова вернуть запрос пароля).

### Основные возможности ветки v3.0
1. **Единый установщик `ClassroomManagerSetup.exe`** (Liquid Glass, тёмная тема): выбор роли (Учитель / Ученик / Оба), автонастройка Брандмауэра Windows, автозагрузка, ярлыки, преднастройка ученика и встроенные разделы «Инструкция», «Решение проблем» и «Полезные команды».
2. **Удалённое управление до 60 FPS** (`1080p` / `720p` / `HD 30 FPS` / `Ультра 1:1`, `TCP_NODELAY`, ускоренный захват `mss`).
3. **Быстрое переключение мониторов прямо на карточке ученика** (`Экран 1` / `Экран 2` рядом с `ONLINE`).
4. **Одновременная работа нескольких учителей и нескольких кабинетов** (параллельные TLS-сессии).
5. **Постоянный список учеников (`ONLINE` / `OFFLINE`)** и удаление карточки через ПКМ.

### Файлы релиза
- **`ClassroomManagerSetup.exe`** — единый установщик (рекомендуется для быстрой установки)
- **`ClassroomTeacher.exe`** — переносимое приложение учителя
- **`ClassroomStudent.exe`** — переносимый агент ученика
- **`setup_firewall.ps1`** — отдельный скрипт открытия LAN-портов Windows Firewall
