## Classroom Manager v2.2.1 – Расширенный MCP (отправка и генерация файлов в любую папку) + UI-полировка

### Что нового в v2.2.1
- **Расширенный MCP-сервер для нейросетей (PowerShell + файлы + выбор путей):**
  - Вкладка **«Терминал PowerShell»** включает локальный MCP-сервер (`http://127.0.0.1:45460/mcp`, защита Bearer-токеном) с кнопкой **«Копировать JSON»** для Antigravity, Claude Desktop, Cursor, VS Code и Windsurf.
  - Полный набор инструментов для ИИ:
    - `browse_local_files` – просмотр файлов на ПК учителя (`@desktop`, `@downloads`, `@documents` или любой путь), чтобы нейросеть сама выбрала нужный файл.
    - `send_file` – отправка локального файла учителя на один ПК или весь класс в любую папку назначения (`@desktop`, `@downloads`, `@documents`, `@public_desktop` или произвольный путь с автосозданием папок и проверкой `SHA-256`).
    - `write_remote_file` – создание файла прямо из текста или `base64` (код, скрипты, конфиги, задания) и мгновенная доставка по нужному пути на ПК учеников с опцией автооткрытия.
    - `list_classrooms`, `list_students`, `get_system_info`, `run_powershell`, `run_powershell_all`, `send_message`, `set_screen_lock`.
- **Исправлены отступы, иконка настроек и типографика:**
  - В разделе **PowerShell** добавлены чёткие отступы между блоками; убрана лишняя пустая полоса «ПК не выбран» при 0 онлайн; иконка настроек заменена на классическую шестерёнку; очищены разделители-точки и длинные тире.

### Файлы релиза (не требуют установки Python)
- **`ClassroomTeacher.exe`** – консоль преподавателя (Liquid Glass UI + мульти-кабинеты + MCP)
- **`ClassroomStudent.exe`** – фоновый агент для компьютеров учеников (системный трей)
- **`setup_firewall.ps1`** – однократная настройка правил Брандмауэра Windows для LAN
